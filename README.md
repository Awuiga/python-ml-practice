# Python & ML Practice

Мои учебные проекты по Python, нейросетям и обработке текста. Здесь собран путь от подсчёта переходов между символами до небольших моделей на PyTorch: XOR, embeddings, предсказание следующего слова, спам и регрессия.

Каждое упражнение можно запускать отдельно. Это небольшие эксперименты для понимания механики обучения, а не готовые прикладные модели. Исходная логика сохранена; при публикации добавлены описание, зависимости и исключения для локальных файлов.

## Запуск на Windows

Для упражнений на чистом Python достаточно стандартной библиотеки. Для PyTorch и NumPy можно создать общее окружение:

```powershell
git clone https://github.com/Awuiga/python-ml-practice.git
cd python-ml-practice
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

python "exercises/проект 2.py"
python "exercises/проект 6.py"
python "exercises/проект 12/project_12.py"
```

Имена со словами и пробелами нужно заключать в кавычки. Скрипты сами запускают обучение и печатают промежуточные результаты.

Для упражнений с сохранением весов запускайте команды из папки упражнения:

```powershell
cd "exercises/проект 8"
python "проект 8.py"
python predict_xor.py
```

`predict_xor.py` требует сначала обучить модель. Файлы весов создаются локально и не включены в Git. Проект №11 спрашивает два слова, например `кот ест`.

## Что учитывать

- Многие примеры учатся на нескольких строках или четырёх вариантах XOR. Точность на обучающих примерах не показывает качество на новых данных.
- В большинстве скриптов случайный seed не фиксирован, поэтому loss и ответы между запусками могут отличаться. Удачное решение XOR не гарантировано для любого случайного старта.
- Это последовательные учебные версии: встречаются повторные определения функций и промежуточные демонстрационные вычисления.
- В №12 размер входного слоя привязан к текущему словарю; тестовые примеры используют известные слова. Изменение текстов может потребовать обновления слоя. Функция `predict_spam` пропускает неизвестные слова.
- В №13 всего восемь вымышленных квартир, две отложены для проверки. Это демонстрация регрессии, а не оценка рыночных цен.
- №14 пока не содержит реализации. Полноценный Transformer вынесен в отдельный [LLM Training Lab](https://github.com/Awuiga/llm-training-lab).

Результаты проверки опубликованных файлов — в [VERIFICATION.md](VERIFICATION.md). Виртуальные окружения, настройки редактора, секреты, веса и рабочие логи исключены из репозитория. Отдельная открытая лицензия на код пока не выбрана автором.
